## 执行方式

**必须由 LLM 直接完成**，而非机械脚本。

每次处理一个年份：
1. 读取 `wiki/shareholders_meeting/YYYY-股东大会.md` 原文
2. LLM 提炼 4-6 条核心要点
3. LLM 精选 2-4 条金句
4. 生成符合格式的 summary，写入 `YYYY-股东大会_summary.md`
