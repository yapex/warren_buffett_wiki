# 巴菲特 Wiki 维护规范

> 本文档定义 Wiki 内容创建和编辑的规范，防止碎片化和信息歧义。

## 一、命名规范（强制）

### 1.1 文件命名

| 规则 | 正确 | 错误 |
|------|------|------|
| 公司页用中文名 | `可口可乐.md` | `Coca-Cola.md` |
| 概念页用中文规范名 | `护城河.md` | `经济护城河.md` |
| 人物页用中文全名 | `查理·芒格.md` | `Charlie Munger.md` |
| 案例页格式：`YYYY-公司名-主题.md` | `1972-喜诗糖果-特许经营权.md` | `1972喜诗糖果.md` |
| 信件页格式：`YYYY-letter.md` | `2011-letter.md` | `2011年信.md` |
| 用中文间隔号 `·` | `斯科特·费泽.md` | `斯科特费泽.md` |
| 英文缩写公司可保留原名 | `IBM.md` | — |

### 1.2 目录结构

```
wiki/
├── companies/       — 公司页（一公司一文件）
├── concepts/        — 概念页（一概念一文件）
├── people/          — 人物页（一人物一文件）
├── letters/         — 致股东信笔记
├── interviews/      — 访谈/演讲笔记
├── shareholders_meeting/ — 股东大会记录
├── research/        — 主题研究
│   └── cases/       — 案例研究
├── partnership/     — 合伙人信笔记
└── special/         — 特殊文档
```

## 二、反例黑名单（禁止做的事）

### 2.1 禁止为同一实体创建多个页面

**典型违规**：为同一公司创建不同翻译名的页面。

```
❌ 内布拉斯加家具城.md + 内布拉斯加家具店.md
✅ 内布拉斯加家具城.md（唯一规范名）

❌ 冰雪皇后.md + 国际冰雪皇后.md
✅ 冰雪皇后.md（唯一规范名）

❌ 韦斯科.md + 韦斯科金融.md
✅ 韦斯科金融.md（唯一规范名）
```

### 2.2 禁止为同一概念创建碎片页面

**典型违规**：核心概念的变体被拆成多个小页面。

```
❌ 护城河.md + 护城河理论.md + 经济护城河.md
✅ 护城河.md（合并所有变体）

❌ 浮存金.md + 保险浮存金.md
✅ 浮存金.md（合并）

❌ 能力圈.md + 能力圈原理.md
✅ 能力圈.md（合并）
```

### 2.3 禁止创建 stub 页面（< 1KB）

每个新页面必须有**实质内容**（≥ 1KB）。如果只有几行信息，应：
- 合并到已有的相关页面
- 或暂时不创建，等有足够内容时再建

### 2.4 禁止中英文文件名混用

```
❌ IBM.md, BNSF.md, GEICO.md（除非是广为人知的缩写）
❌ Clayton%20Homes.md（URL 编码出现在文件名中）
✅ 可口可乐.md, 伯灵顿北方铁路.md, 盖可保险.md
```

### 2.5 禁止在链接中使用英文别名

```
❌ [GEICO](../companies/GEICO.md)
✅ [盖可保险](../companies/盖可保险.md)

❌ [BNSF](../companies/BNSF.md)
✅ [伯灵顿北方铁路](../companies/伯灵顿北方铁路.md)
```

## 三、页面质量标准

### 3.1 frontmatter（强制）

每个页面必须有 YAML frontmatter：

```yaml
---
type: company          # company | concept | person | letter | interview | case_study | shareholders_meeting
name: 可口可乐          # 规范名称
english_name: Coca-Cola  # 可选
first_appeared: 1988   # 首次出现的年份
tags: [消费品牌, 食品]  # 可选
---
```

### 3.2 公司页模板

```markdown
# 公司名

## 公司简介
（一段话概述）

## 巴菲特投资历程
### 时间线
| 年份 | 事件 |

### 投资概要
| 维度 | 数据 |

## 核心投资逻辑
- [概念链接] — 简要说明

## 案例研究
- [案例链接]

## 相关信件
- [信件链接]

## 相关人物
- [人物链接]
```

### 3.3 内容来源优先级

1. **巴菲特亲笔信**（最高优先级）
2. 巴菲特访谈/演讲原文
3. 股东大会问答记录
4. 二手资料（注明来源）

### 3.4 引用规范

引用巴菲特原文时使用 blockquote：

```markdown
> "原文内容"
>
> —— 巴菲特，YYYY 年致股东信
```

## 四、维护检查清单

创建或编辑页面后，逐项检查：

- [ ] 文件名符合命名规范（中文、间隔号、无重复）
- [ ] 有 frontmatter 且 type 字段正确
- [ ] 所有内部链接指向真实存在的文件
- [ ] 没有为同一实体创建第二个页面
- [ ] 内容 ≥ 1KB（非 stub）
- [ ] 引用巴菲特原文时标注了来源年份
- [ ] 有至少一个双向链接（被其他页面引用）

## 五、LLM 查询友好性

作为 LLM Wiki，每个页面应考虑 LLM 查询效率：

1. **核心信息前置**：最重要的数据放在页面顶部，不要藏在底部
2. **关键词完整**：公司页标题包含中文+英文名，如 `# 可口可乐 (Coca-Cola)`
3. **年份明确**：所有投资数据标注年份，LLM 常按时间查询
4. **原文可追溯**：引用巴菲特原文时标注"YYYY 年致股东信"，便于 LLM 引导用户查阅原始信件
